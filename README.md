# Dario Chaves | Portfolio

Personal portfolio built for the Programación 3 course at UTN (Tecnicatura Universitaria en Programación). It is a single static page made with HTML, CSS and vanilla JavaScript.

**Live site:** https://tu-usuario.github.io/nombre-del-repo/

## Sections

- **About me:** short professional background.
- **Skills:** technology icons (HTML, CSS, JavaScript, C#, C++, GitHub, Jira).
- **Education:** UTN University Technical Degree in Programming and a MERN Stack (Backend) course at Coderhouse.
- **Projects:** project cards, plus a form to add new ones.
- **Contact:** social media links and a contact form.

## Features

- Light/dark theme toggle that remembers your choice (`localStorage`) and follows the system preference by default.
- Add project cards from a form (they live in memory, so they disappear when the page reloads).
- Contact form that opens Gmail with the message ready to send.
- Responsive layout built with Flexbox.

## Tech

HTML5 · CSS3 (Flexbox, custom properties) · JavaScript (DOM, events, Web Storage)

## Run it locally

Download or clone the repo and open `index.html` in your browser. No build step or dependencies needed.
